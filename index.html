يلزم ضبط رابط Google Apps Script

افتح ملف config.js في مستودع GitHub، واستبدل النص الموجود فيه برابط Web app الذي ينتهي بـ /exec، ثم احفظ التعديل.

window.LOHAT_APPS_SCRIPT_URL = 'https://script.google.com/macros/s/…/exec';

بعد ذلك أعد تحميل صفحة GitHub Pages.
